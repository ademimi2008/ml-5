Подбор порога классификации под цену ошибки

Учебный проект (уровень B, данные заданы). Задача: обучить модель, получить вероятности классов, подобрать порог классификации под заданную цену ошибок и сравнить его с порогом по умолчанию 0,5.

Данные

Файл personality_synthetic_dataset.csv: 20 000 строк, 30 колонок, пропусков нет.

Целевая колонка personality_type имеет три класса: Extrovert, Ambivert, Introvert.
Остальные 29 колонок — числовые признаки (оценки от 0 до 10), например social_energy, talkativeness, empathy.
Данные синтетические, классы почти полностью разделимы.

Для бинарной постановки положительным классом (1) выбран Introvert (33% данных), остальные два класса объединены в класс 0.

Установка и запуск
Установите Python 3.9+ и расширения VS Code Python и Jupyter.
Откройте папку проекта в VS Code (File → Open Folder).
Откройте терминал (Terminal → New Terminal) и выполните:
   python -m venv .venv
   .venv\Scripts\activate
   pip install pandas numpy scikit-learn matplotlib ipykernel

На Mac и Linux вторая команда: source .venv/bin/activate. 4. Выберите интерпретатор из .venv (внизу справа или Ctrl+Shift+P → Python: Select Interpreter). 5. Откройте main.py и запускайте ячейки сверху вниз кнопкой Run Cell или Shift+Enter.

Настройки

В первой ячейке main.py задаются параметры:

Параметр	Значение	Описание
DATA_PATH	personality_synthetic_dataset.csv	путь к данным
POSITIVE_CLASS	Introvert	класс, считающийся положительным
C_FP	из задания (по умолчанию 1)	цена ложноположительного результата
C_FN	из задания (по умолчанию 5)	цена ложноотрицательного результата

Цены C_FP и C_FN нужно взять из описания преподавателя. Значения по умолчанию временные.

Что делает код
Ячейка	Действие
1	Импорты и настройки
2	Загрузка данных, бинаризация цели
3	Разбиение 60/20/20 на train / val / test со стратификацией
4	Обучение логистической регрессии, получение predict_proba
5	Функция оценки: метрики и матрица ошибок с подписанными осями
6	ROC- и PR-кривые, ROC AUC и PR AUC
7	Подбор порога по минимуму суммарной цены C_FP·FP + C_FN·FN на val
8	Сравнение порога 0,5 и подобранного порога на test
9	Базовая линия accuracy и проверка, что порог отличается от 0,5

Порог подбирается на валидационной выборке, итоговое сравнение выполняется на тестовой, которую модель и подбор порога не видели.

Результаты

Получены при C_FP = 1, C_FN = 5, random_state = 42. При других ценах числа изменятся.

Метрика	Порог 0,50	Порог 0,13
Accuracy	0,999	0,998
Precision	0,999	0,994
Recall	0,998	1,000
F1	0,998	0,997
FP	1	8
FN	3	0
Суммарная цена	16	8
ROC AUC ≈ 1,000, PR AUC ≈ 1,000.
Подобранный порог снизил суммарную цену ошибок в два раза за счёт роста ложных тревог.
Вывод

Порог 0,5 считает обе ошибки одинаково важными, поэтому он не подходит, когда цены ошибок различаются. Критерием выбора взята суммарная цена ошибок, а не accuracy. При дорогом ложноотрицательном результате оптимальный порог ниже 0,5: recall растёт, precision слегка падает.

ROC AUC — вероятность того, что случайный интроверт получит от модели вероятность выше, чем случайный не-интроверт (0,5 — угадывание, 1,0 — идеальное разделение). Значение около 1,0 объясняется синтетической природой данных, поэтому разница между порогами здесь небольшая.

Возможные проблемы
Проблема	Решение
ModuleNotFoundError	Выберите интерпретатор .venv и повторите pip install ...
FileNotFoundError	Поместите CSV в папку проекта и проверьте DATA_PATH
Нет кнопки Run Cell	Установите расширение Jupyter, проверьте строки # %%
Precision или Recall равны 0	Проверьте, что POSITIVE_CLASS совпадает с названием класса в данных
Порог равен 0,5 или лежит на краю	Проверьте, что C_FP и C_FN не перепутаны
Требования к сдаче
 Матрица ошибок с подписанными осями
 Precision, recall, F1, а не только accuracy
 ROC- и PR-кривые, значения AUC и их объяснение
 Явное обоснование порога, отличного от 0,5
 Сравнение порогов и вывод
